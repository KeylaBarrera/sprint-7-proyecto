# Análisis de anuncios de venta de coches

Panel de control (dashboard) interactivo para explorar un conjunto de datos de anuncios de venta de vehículos. Está construido con Streamlit y desplegado en la nube.

🔗 **[Ver la aplicación desplegada](https://sprint7-proyecto-2vid.onrender.com)**

## Objetivo del proyecto

Construir y desplegar una aplicación web en un servicio en la nube, poniendo en práctica tareas típicas de ingeniería de software:

- Crear y gestionar entornos virtuales de Python.
- Desarrollar una aplicación web con un dashboard interactivo.
- Desplegar la aplicación en un servicio en la nube (Render).

## Funcionalidades

- **Histograma de kilometraje:** muestra la distribución del odómetro de los vehículos.
- **Gráfico de dispersión:** compara el precio del vehículo con su kilometraje.

## Tecnologías

- Python
- pandas
- Plotly
- Streamlit
