# sprint-7-proyecto - Análisis de anuncios de venta de coches
Objetivo del proyecto  Construir y desplegar un panel de control (dashboard) de una aplicación web en un servicio en la nube, poniendo en práctica tareas típicas de ingeniería de software: crear y gestionar entornos virtuales de Python y desarrollar una aplicación web.

# Librerias y paquetes
- python, pandas, plotly, streamlit

# Funcionalidad
- Visualiza un histograma de la distribución del kilometraje (odómetro) de los vehículos.
- Visualiza un gráfico de dispersión que compara el precio del vehículo con su kilometraje.
